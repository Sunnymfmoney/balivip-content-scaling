# Prompt: Ten reels from one folder

## Inputs needed
- The folder path
- The wedding type and what stood out
- Any review from this couple

## The prompt

```
Plan ten reels from this wedding folder.

Folder:    [path]
Type:      [Indian / international / Chinese / western / mixed]
Stood out: [what was notable]
Review:    [paste, or "none"]

Step 1. Sort what is in the folder into motion, detail, room, and people. Tell me
what is missing.

Step 2. Assign the ten shapes from sop/drive-folder-to-10-reels.md to the footage
that actually exists. If a shape has no footage, say so rather than forcing it.

Step 3. For each reel give me:
  - three hook options for the first 1.5 seconds, motion never a portrait
  - the timed shot list
  - on-screen text
  - the caption, ask on the first line

Seven aesthetic or authority, one conversion, two flexible.

No clip may appear in two reels going out the same week.

Read playbooks/reels.md first.
```

## Output format
The sort, the ten assignments, then hooks, shot lists and captions.

## Quality standard
Every shot list matched to real footage. No invented b-roll.

## Brand rules
Consent confirmed. No venue named without clearance. No invented numbers.

## CTA rules
Three asks maximum across ten reels.
