# Prompt: Venue content

## Inputs needed
- The setting type, not the venue name
- The footage or photographs
- Whether the venue has been cleared to be named

## The prompt

```
Write venue content for BaliVIP.

Setting:   [clifftop / beach / chapel / villa estate / garden / ballroom]
Assets:    [folder or codes]
Named:     [yes, cleared for this post / NO]
Format:    [reel / carousel / story]
Type:      [aesthetic / authority]

Teach what this KIND of setting physically requires. Access, curfew, weather,
capacity, where the groom's car turns around, whether there is a real indoor room.

If "Named: NO", do not name the venue anywhere, including the caption.

Read playbooks/venue-spotlights.md first.
```

## Output format
Hook options, the slides or shot list, and a caption.

## Quality standard
Wide shots held long. One lesson attached. No ranking.

## Brand rules
Never name a venue without clearance for that specific post. Never rank venues. Never
imply a partnership or exclusivity that does not exist.

## CTA rules
"Tell us your ceremonies" works well here. Pure aesthetic venue posts need no ask.
