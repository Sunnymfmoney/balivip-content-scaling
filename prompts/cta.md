# Prompt: CTA

## Inputs needed
- What the post taught
- Where you want them to go
- Whether the destination exists and is tested

## The prompt

```
Write the ask for this BaliVIP post.

Post taught:  [the one idea]
Destination:  [comment keyword / DM / link in bio / WhatsApp / form]
Deliverable:  [what they actually receive]
Speed:        [same day / within an hour / etc]

Give me three options, then recommend one.

Formula: [what they do] and [what you send] [how fast]. [What they do not have to do.]

The ask must answer what the post taught. If the post is about counting events, the
ask is about ceremonies, not dates.

Read strategy/03-cta-and-conversion-rules.md first.
```

## Output format
Three options, one recommendation, plus the on-slide version if it is shorter.

## Quality standard
- Names the deliverable, not "more info"
- Names the speed
- Removes the objection, usually "no form, no call"
- Answers the post

## Brand rules
No false urgency. No begging. No exclamation mark. No emoji arrows. No all caps.

## CTA rules
One ask. If the caption promises "no form", the destination cannot be a form.
