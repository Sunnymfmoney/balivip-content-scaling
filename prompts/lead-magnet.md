# Prompt: Lead magnet content

## Inputs needed
- What the magnet actually is, and whether it exists yet
- The keyword or link
- Whether the automation is live and tested

## The prompt

```
Write lead magnet content for BaliVIP.

Magnet:      [what they receive]
Exists:      [yes / no]
Destination: [comment keyword / link in bio / DM]
Keyword:     [if applicable]
Automation:  [live and tested / not built yet]
Format:      [reel / carousel / story]

If "Exists: no" or "Automation: not built yet", say so and stop. Do not write a post
that promises something that is not there.

Structure: name the fear, name the deliverable, name the speed, remove the objection,
one ask.

Read playbooks/lead-magnets.md and strategy/03-cta-and-conversion-rules.md first.
```

## Output format
The post, the caption, and the exact DM script the automation should send.

## Quality standard
The deliverable is specific. The speed is named. The objection is removed.

## Brand rules
Never promote something that does not exist. Never promise "no form" and then link a
form. The DM has to sound like a person, not a bot.

## CTA rules
Comment keyword performs best. Never send a cold audience to an enquiry form.
