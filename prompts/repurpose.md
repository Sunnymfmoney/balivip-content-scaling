# Prompt: Repurpose old assets

## Inputs needed
- What already exists
- How it performed, if known
- How long ago it went out

## The prompt

```
Repurpose this for BaliVIP.

Original:    [link, path, or description]
Format was:  [reel / carousel / story]
Performance: [reach, saves, DMs if known]
Posted:      [when]

Tell me which of these applies:
- Good idea, bad hook. Rewrite frame one and repost
- Good post, wrong format. Convert it
- Good post, wrong ask. Change the destination
- Still good. Repost as is after 8 weeks
- Retire it

Then do it.

Rules:
- A post with low reach and high saves is a hook problem, not a content problem.
  Those are the best repurposing candidates in the account
- Do not repost inside 6 weeks
- Update anything that has since become inaccurate
```

## Output format
The diagnosis, then the rebuilt asset.

## Quality standard
A repurpose is a real rewrite, not a re-crop. If nothing changed except the size, it
was not worth doing.

## Brand rules
Re-check every claim. Something true six months ago may not be. Re-check consent if a
couple appears.

## CTA rules
Old posts often carried a dead destination. Check it before reposting.
