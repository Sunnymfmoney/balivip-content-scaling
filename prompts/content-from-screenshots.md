# Prompt: Content from screenshots, links and folders

## Inputs needed
- The screenshots, links, or folder path
- What you think is in there
- What you want out

## The prompt

```
Here are some assets. Turn them into BaliVIP content.

Assets:  [paths, links, or attached screenshots]
Context: [what this is, e.g. "a wedding we did in June", "a competitor post I liked",
          "a DM conversation", "a venue we just visited"]
Want:    [how many posts, which formats]

Tell me first:
1. What is actually usable and what is not
2. What is missing before this can be posted
3. Whether consent is needed and from whom

Then write what you can.

If a screenshot contains someone's private message, a real name, a price, or a
booking detail, flag it and do not reproduce it.
```

## Output format
An honest assessment first, then the posts.

## Quality standard
Do not invent context to fill a gap. If the folder does not say what wedding it was,
say so and ask.

## Brand rules
Never reproduce a private message, a real name, a price, or a booking detail from a
screenshot. Never post a competitor's asset. Never use a screenshot with browser or
app UI in it as a finished asset. Rebuild it in brand.

## CTA rules
Standard rules apply.
