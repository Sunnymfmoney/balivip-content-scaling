# Prompt: Reel

## Inputs needed
- The footage or photographs available, and where they are
- The one idea
- Segment and type
- The ask
- Length

## The prompt

```
Write a reel for BaliVIP.

Idea:      [one sentence]
Footage:   [what exists, and the folder path]
Segment:   [Indian / international / Chinese / western / all]
Type:      [aesthetic / authority / conversion]
Ask:       [the one CTA, or "none"]
Length:    [15-30] seconds

Give me:
1. Three hook options for the first 1.5 seconds. Motion, never a static portrait
2. The shot list, timed, against the footage that actually exists
3. On-screen text per beat
4. Subtitles if there is a voiceover
5. The caption, ask on the first line

Read playbooks/reels.md first.

If I ask you to build it, use the video/ HyperFrames project, then run
npx hyperframes check before rendering.
```

## Output format
Hooks, timed shot list, on-screen text, caption.

## Quality standard
- Motion in frame one
- One idea, not three
- Text readable on mute, never over a face
- Under 30 seconds unless the footage earns more

## Brand rules
Real footage only. Calm pacing. No trending audio that fights the mood. No invented
numbers. Consent confirmed before any couple appears.

## CTA rules
One ask in the last 3 seconds, on screen and in the caption. Most aesthetic reels
should have no ask at all.
