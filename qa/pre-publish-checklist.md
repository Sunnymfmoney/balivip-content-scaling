# Pre-publish checklist

Run `make check` first. It catches banned claims, em dashes, trimmed reviews and
wrong image sizes. Everything below is what no script can check.

## Copy

- [ ] Every headline stands alone if screenshotted and sent to one person
- [ ] One idea per slide, no slide repeats another
- [ ] No em dashes anywhere, caption included
- [ ] Every number is traceable to a source. If not, it is out
- [ ] No venue named without clearance for this specific post
- [ ] No trade jargon. If the team has to ask, it does not publish
- [ ] Spelling is American: center, color, makeup
- [ ] Caption's first line is the ask

## Reviews

- [ ] Word for word against the actual Google review
- [ ] Name spelled exactly as it appears on Google
- [ ] The photograph is that reviewer's own wedding
- [ ] If it goes on a paid ad, the couple has been asked

## Visual

- [ ] No copy on a face
- [ ] No copy on the bright part of a photograph
- [ ] No photograph repeated inside this set
- [ ] Correct fonts. Cormorant Garamond and Jost, not a fallback
- [ ] Correct size: 1080x1350 feed, 1080x1920 story and reel
- [ ] Story and reel copy clears the top and bottom 250px
- [ ] Carousel slides upload in the right order

## The ask

- [ ] Exactly one ask
- [ ] The ask answers what the post taught
- [ ] The ask names the deliverable and the timing
- [ ] No false urgency, no begging, no exclamation mark in the ask

## The destination

- [ ] There is a row in `automations/post-to-automation-map.md`
- [ ] The automation is live, not draft
- [ ] Tested from a second account, today
- [ ] The keyword in the caption matches the keyword in the automation exactly
- [ ] If the caption promises "no form", the destination is not a form
- [ ] Link opens on mobile data
- [ ] UTM parameters present
- [ ] Someone is watching the inbox

## Consent

- [ ] The couple agreed to this being posted
- [ ] The agreement covers this use: feed, story, or ad

## The two questions

- [ ] **Would this attract an enquiry?** If it is aesthetic and the answer is no,
      fine, that is its job. If it is conversion and the answer is no, rewrite it.
- [ ] **Would this cheapen the brand?** Would a couple spending a large sum on the
      most irreversible day of their life feel more confident after seeing this, or
      less? Less means do not post it, whatever the reach might be.
